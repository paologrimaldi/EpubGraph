Getting Started

System Requirements

  • OS: macOS 10.15+, Windows 10+, or Linux
  • RAM: 4 GB minimum, 8 GB recommended
  • Disk: ~100 MB for the app, ~8 KB per book for embeddings
  • Optional: Ollama for AI-powered recommendations

First Launch

Go to Settings and click the + button next to "Libraries"

Select a folder containing your EPUB files (Calibre libraries auto-detected)

EpubGraph scans, extracts metadata, cover images, subjects, and chapter titles

Pointer-Based Storage

EpubGraph never copies or modifies your files. It creates pointers to their existing locations on disk.

Managing Libraries

Adding & Scanning

Add multiple library folders to organize your collection. Click the refresh icon to re-scan for new or changed books. EpubGraph preserves your ratings, read status, and hidden-book flags between scans.

Metadata Extraction

During scanning, EpubGraph extracts rich metadata from each EPUB:

  • Core metadata: title, author, series, publisher, description, language, ISBN
  • Subject tags: dc:subject elements from the OPF manifest (genre, topics, Library of Congress headings)
  • Chapter titles: extracted from the EPUB Table of Contents (NCX/nav), including nested sections
  • Cover images: auto-extracted and cached locally

Calibre Libraries

Folders containing metadata.db are automatically recognized as Calibre libraries. All metadata, ratings (converted to 1-5 scale), tags, and cover images are imported non-destructively.

Browsing Books

Library View

The main view displays your books in a virtualized, responsive grid. Each card shows the cover, title, author, rating stars, and a colored read-status dot. The grid lazy-loads as you scroll, handling libraries of any size.

Sorting & Search

Use the sort selector to order by title, author, date added, rating, series, publish date, or random shuffle. The search bar uses FTS5 full-text search with weighted ranking (title 10x, author 5x, series 3x, description 1x).

Right-Click Context Menu

Right-click any book card for quick actions:

  • Add/Remove from Up Next — manage your reading queue
  • Open Book — launch in your default EPUB reader
  • View Details — open the detail sidebar
  • Hide / Unhide Book — toggle visibility
  • Delete Book — remove from library and send to Trash
  • Hide All by Author / Delete All by Author — batch operations

Book Details

Click any book to open the details sidebar with full metadata, description, AI-generated recommendations, and controls for rating, read status, and Up Next.

Hide & Delete Books

Hiding Books

Hide books you don't want to see without removing them. Hidden books are:

  • Removed from the library grid (unless "Show Hidden" is enabled)
  • Excluded from AI recommendations and the book graph
  • Deprioritized in the embedding processing queue (processed last, not skipped)

Toggle the Eye icon in the library header to reveal hidden books. They appear dimmed at 45% opacity with an eye-off badge.

Deleting Books

Delete permanently removes the book from the database and sends the source file to the OS Trash (recoverable). For Calibre-style book folders, EpubGraph detects the parent folder and asks whether to trash just the EPUB or the entire folder (including cover.jpg, metadata.opf).

Deletion also cleans up all related data: embeddings, graph edges, ratings, tags, summaries, and Up Next entries.

Keyboard Shortcuts

Hide / Unhide selected book H
Delete selected book Delete

Batch Operations

Right-click any book and choose "Hide All by Author" or "Delete All by Author" to apply the action to every book by that author. Delete by author asks for confirmation and offers the folder-vs-file choice.

Recoverable Deletion

Files are sent to the OS Trash, not permanently deleted. You can restore them from your system's Trash/Recycle Bin.

AI Recommendation Engine

Embedding Model

EpubGraph uses qwen3-embedding:8b, an 8-billion parameter embedding model producing 2048-dimensional vectors via Matryoshka Representation Learning (MRL) truncation from the native 7168 dimensions. This provides ~3x the semantic capacity of the previous 768-dimensional model while keeping storage at ~8 KB per book.

Summary-then-Embed Pipeline

Rather than embedding raw metadata, EpubGraph generates a semantically dense summary for each book, then embeds that summary. This captures genre, themes, tone, narrative style, target audience, and comparable works — exactly the signals that drive good recommendations.

Recommendation Algorithm

The Discover page uses a smart recommendation system:

  1. Seed selection: Up Next books (1.2x weight) + highly-rated books (4-5 stars)
  2. Graph traversal: follows pre-computed similarity edges (threshold ≥ 0.3)
  3. Filtering: excludes finished, abandoned, and hidden books from results
  4. MMR diversity: Maximal Marginal Relevance uses actual content similarity (not score difference) to avoid redundant recommendations
  5. Author diversity: maximum 3 books per author in top results

Setting Up Ollama

# Install Ollama
brew install ollama

# Pull the required models
ollama pull qwen3-embedding:8b    # Embedding model (required)
ollama pull mistral:7b             # Chat model for summaries (recommended)

# Start the server
ollama serve
Pause-Safe Processing

Embedding generation runs in the background and is safely pausable. Close the app anytime — it resumes exactly where it left off. Summaries are cached independently so no work is repeated.

Book Graph

The Graph View renders your library as a force-directed network using Sigma.js. Each node is a book; edges represent discovered relationships. Hidden books are automatically excluded from the graph.

Using the Graph

Navigate to "Book Graph" in the sidebar

Search or select a book to center the graph on

Adjust depth (1-3 hops) and max nodes (10-100)

Hover nodes to highlight connections, click to view details

Edge Types

  • Blue — Similar content
  • Green — Same author
  • Amber — Same series
  • Purple — Shared tags

Controls

  • Zoom: scroll wheel or +/- buttons
  • Pan: click and drag the background
  • Reset: click the reset button to re-center

Ratings & Read Status

Rating Books

Click stars in the book details panel to rate 1-5. Ratings directly influence which books seed your AI recommendations — books rated 4+ become recommendation seeds with weighted priority.

Read Status

  • Unread — default state
  • Want to Read — auto-added to Up Next
  • Reading — currently in progress
  • Finished — excluded from recommendations
  • Abandoned — excluded from recommendations

Calibre Import

Point EpubGraph at any folder containing a metadata.db file to auto-import a Calibre library. All book metadata, ratings (converted to 1-5 scale), tags, series information, and cover images are imported. EpubGraph reads from Calibre's database but never modifies it.

Calibre Folder Structure

When deleting books from a Calibre library, EpubGraph detects the book folder pattern (epub + cover.jpg + metadata.opf) and offers to trash the entire folder.

Backup & Export

Full Database Backup

Settings → "Create Backup" saves a complete copy of library.db, which contains all data: book metadata, ratings, embeddings, graph edges, summaries, and hidden states. This is the recommended backup method.

JSON Export

Settings → "Export Library" saves metadata and ratings as a portable JSON file. This does not include embeddings or graph data — those will be regenerated on import. Use this for migrating between machines or sharing library metadata.

Restore

Use "Restore Backup" (for .db files) or "Import Library" (for JSON) to restore your data.

Settings

Ollama Configuration

  • Endpoint: Ollama server URL (default: http://localhost:11434)
  • Embedding Model: qwen3-embedding:8b (2048-dim, 8B parameters)
  • Chat Model: mistral:7b (used for summary generation)

Processing

  • Batch Size: number of books to process per cycle (default: 10)
  • Pause/Resume: control background embedding generation
  • Auto-scan: periodically check for new books

Troubleshooting

Books Not Appearing

  • Ensure files have the .epub extension
  • Check the "Show Hidden" toggle — books may be hidden
  • Try re-scanning the library from the sidebar
  • Verify the folder path is accessible (external drives, network shares)

Ollama Not Connecting

  • Verify Ollama is running: ollama serve
  • Check the endpoint URL in Settings
  • Ensure models are pulled: ollama pull qwen3-embedding:8b
  • If only the chat model is missing, summaries are skipped and raw metadata is embedded instead (fallback mode)

Slow Performance

  • Embedding generation runs in the background at ~2-5 seconds per book with the chat model
  • Use "Pause" in Settings to stop processing during heavy use
  • Large graph views (>100 nodes) may be slower — reduce max nodes in controls
  • The 3D bookshelf requires WebGL support

Recommendations Not Showing

  • Rate some books (4-5 stars) or add books to Up Next — these become recommendation seeds
  • Wait for embedding processing to complete (check status in Settings)
  • Ensure Ollama is running for initial processing
