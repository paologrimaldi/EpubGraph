EpubGraph User Manual

Your guide to the AI-powered ebook library manager

Getting Started

System Requirements

  • Operating System: macOS 10.15+, Windows 10+, or Linux
  • Memory: 4GB RAM minimum, 8GB recommended
  • Storage: 100MB for the application
  • Optional: Ollama for AI-powered recommendations

First Launch

When you first launch EpubGraph, you'll see an empty library. Follow these steps to get started:

Click the + button next to "Libraries" in the sidebar

Select a folder containing your EPUB files

EpubGraph will scan the folder and import all found books

Non-Destructive Storage

EpubGraph doesn't copy your books - it creates pointers to their locations. Your files stay exactly where they are!

Managing Libraries

Adding a Library

You can add multiple library folders to organize your books. Click the + button in the sidebar, navigate to your book folder, and select it.

Scanning for New Books

Click the refresh icon next to a library to scan for new or changed books. EpubGraph will:

  • Find new EPUB files added since the last scan
  • Update metadata for modified files
  • Preserve your ratings and read status

Calibre Libraries

EpubGraph automatically detects Calibre libraries and imports all metadata, ratings, tags, series information, and cover images.

Browsing Books

Library View

The main view shows all your books in a responsive grid. Each book card displays the cover image, title, author, your rating, and read status badge.

Searching

Use the search bar (Cmd + K) to find books. EpubGraph uses full-text search across titles, authors, series names, and descriptions.

Right-Click Menu

Right-click any book to access quick actions:

  • Add to Up Next: Add to your reading queue
  • Open Book: Open the EPUB file in your reader
  • View Details: Open the book details sidebar

Book Details

Click any book to view its details panel with full metadata, description, AI-generated recommendations, and controls for rating and read status.

Up Next - 3D Reading Queue

Up Next is your personalized reading queue displayed in an interactive 3D bookshelf. Browse your books on a beautiful virtual shelf, with realistic lighting and smooth animations.

3D Bookshelf

Browse your queue on a realistic virtual bookshelf with spine and cover textures

Smart Queue

Automatically includes books marked as "Want to Read"

Manual Curation

Add any book to Up Next from the library view

Interactive

Click books to view details, hover to preview covers

Adding Books to Up Next

There are three ways to add books to your Up Next queue:

From Book Details: Click any book in the library, then click "Add to Up Next" in the details sidebar

Right-Click Menu: Right-click any book thumbnail and select "Add to Up Next"

Automatic: Set a book's status to "Want to Read" - it will automatically appear in Up Next

Using the 3D Bookshelf

  • Navigate: Scroll horizontally to browse books, use arrow keys for keyboard navigation
  • Hover: Hover over a book to see it pull forward slightly and preview its cover
  • Select: Click a book to view its full details in the sidebar
  • Remove: In the details sidebar, click "Remove from Up Next" to remove the book
Smart Status Handling

When you change a book's status (e.g., mark as "Reading" or "Finished"), the book is automatically removed from Up Next since you've moved past the "want to read" stage.

AI Recommendations

How It Works

EpubGraph uses a hybrid recommendation system combining content similarity, author relationships, series connections, and your personal preferences.

Similar Content

AI analyzes descriptions to find similar themes and writing styles

Same Author

Discover more works by authors you enjoy

Series

Find the next books in series you're reading

Personalized

Based on your highly-rated books

Setting Up Ollama

For AI-powered recommendations, install Ollama:

# macOS
brew install ollama

# Start Ollama and pull the model
ollama serve
ollama pull nomic-embed-text

The sidebar shows Ollama's connection status. When connected, EpubGraph automatically generates embeddings in the background.

Book Graph

The Graph View visualizes relationships between your books as an interactive network.

Using the Graph

Click "Book Graph" in the sidebar

Select a book to center the graph on

Explore connections by hovering over nodes

Click a node to view that book's details

Edge Colors

  • Blue: Similar content
  • Green: Same author
  • Amber: Same series
  • Purple: Shared tags

Controls

  • Zoom: Use + and - buttons or scroll wheel
  • Pan: Click and drag the background
  • Reset: Click the reset button to center the view

Ratings & Read Status

Rating Books

In the book details panel, click stars to rate a book from 1 to 5. Your ratings help improve personalized recommendations.

Read Status

Track your reading progress with these status options:

  • Unread - Haven't started yet
  • Want to Read - On your reading list (appears in Up Next)
  • Reading - Currently in progress
  • Finished - Completed reading
  • Abandoned - Stopped reading

Calibre Import

EpubGraph seamlessly imports from Calibre libraries. When you add a folder containing a metadata.db file, EpubGraph recognizes it as a Calibre library and imports all book metadata, ratings (converted to 1-5 scale), tags, and cover images.

Non-Destructive

EpubGraph reads from Calibre's database but never modifies it. Your Calibre library remains unchanged.

Backup & Export

Exporting Your Library

Go to Settings and click "Export Library" to save your library data (metadata, ratings, read status, file paths) to a JSON file.

Importing

Go to Settings, click "Import Library", select your export file, and choose a merge mode (replace, skip, or merge).

Database Backup

For a complete backup including all data, go to Settings and click "Create Backup" to save the .db file.

Settings

Ollama Configuration

  • Endpoint: Ollama server URL (default: http://localhost:11434)
  • Model: Embedding model to use (default: nomic-embed-text)

Library Settings

  • Auto-scan: Automatically scan for new books periodically
  • Scan Interval: How often to check for new books

Recommendation Settings

  • Max Recommendations: Number of recommendations to show
  • Embedding Batch Size: Books to process at once

Troubleshooting

Books Not Appearing

  • Ensure files have the .epub extension
  • Try re-scanning the library
  • Check that the folder path is accessible

Ollama Not Connecting

  • Verify Ollama is running: ollama serve
  • Check the endpoint in Settings
  • Ensure the model is pulled: ollama pull nomic-embed-text

Slow Performance

  • Large libraries (100K+ books) may take time to load initially
  • Embedding generation happens in the background
  • Graph view with many nodes may be slower

3D Bookshelf Issues

  • Ensure your browser supports WebGL
  • Try refreshing the page if textures don't load
  • Reduce the number of books in Up Next if performance is slow
