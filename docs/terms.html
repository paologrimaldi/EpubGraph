EpubGraph operates entirely on your local machine. The Software:

  • Does not collect, transmit, or store any personal data on external servers

4. File Handling

EpubGraph uses a pointer-based storage model:

  • The Software creates references to your EPUB files but does not copy them
  • The "Delete" function sends files to your operating system's Trash/Recycle Bin (recoverable)
  • The Software reads from Calibre databases but never modifies them
  • Cover images may be cached locally for performance
